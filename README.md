# Card Shop co-op modpack updates

Windows updates for the unofficial co-op modpack for **TCG Card Shop Simulator**.

### Install the updater for the first time

If you already have the full 1.7.0.0, 1.8.0.0 or 1.9.0.0 Pokémon co-op pack, close the game and extract the Windows setup ZIP. Open **ShopSetup.exe**, confirm the game folder, and choose **Apply update**. [Download Windows setup](https://github.com/CalamityTheWatcher/CardShopCoop-Updates/releases/download/v1.12.0.2/CardShopCoop-1.12.0.2-Windows-Setup.zip)

On a new PC, install the game through Steam and get the **full Pokémon co-op setup ZIP** from your host. Extract the whole archive and open **ShopSetup.exe**. In **TCG Overhaul Installer**, choose **Install**, then **Open game** once setup finishes.

If you used the older Windows setup to add the updater, open the game and accept the latest pack update.

### Update from the game

The game checks for releases when it starts and every minute while you play. Choose **Close** to keep playing or **Update** to download the release. Updating the host ends the current co-op session. Once the files are ready, the game restarts and shows the changes. Press the red **Close** button to continue, then invite your friend back when both PCs are up to date.

Starting with 1.13.0.0, the prompt can open at your register. **Close** returns you to the same customer with your scan, keypad entry and change preserved. **Update** finishes that customer’s sale and credits the shared till once. Customers still in line keep their place during checkout completion.

When updating from an older installer, Steam may ask you to open the game from your Library once. The update is already installed. On subsequent updates the installer waits for Steam to finish the previous session and reopens the game automatically.

This feed delivers updates selected and tested together for the pack, including co-op fixes, patched mods, and content changes. [Read the release notes](https://github.com/CalamityTheWatcher/CardShopCoop-Updates/releases)
